## What it does

`main.py` (Python 3, standard library only) writes one short family scene,
warm, funny and heartfelt, to `/output/entry.txt`. The scene stays inside
the gate: one line, well under 280 characters.

The scene: Dad fixes the wobbly table leg with a folded coaster, Mom
declares it a family heirloom, and the little brother guards it like a
museum piece at every dinner.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
